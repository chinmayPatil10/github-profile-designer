# Example profiles

One example README per design, all for **Ada Example**, a made-up developer. Use them as starting points and rewrite the content for the real person.

Live widgets need a real account, so in these files the stats cards, streak, contribution chart and pin cards point at GitHub's demo account [`octocat`](https://github.com/octocat). Snake images, guestbook entries and poll results only appear after the GitHub Actions run in a real profile repo.
